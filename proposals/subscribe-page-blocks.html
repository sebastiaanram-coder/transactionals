Subscribe page — the commercial block, per locale

Klaviyo's hosted subscribe page cannot be edited through the API, so this is the block to paste in yourself. One per language, because the page's language cannot be detected from inside a block — see the note below.

How to add it
  1. Open the subscribe page editor, Subscribe page tab.
  2. Drag an HTML block to the top, above the Email field.
  3. Paste the English block below.
  4. Open translations and paste each language's block into its own version. That is what keeps the block in the same language as the labels next to it.
  5. While you are there: consider deleting First name and Last name. Three fields to claim a discount is friction, and Email is the only required one.

Why nine blocks and not one that detects the language
  1. A ?lang= or ?locale= parameter does not switch language — it flips the page into unsubscribe mode.
  2. document.documentElement.lang is en and stays en.
  3. Accept-Language changes nothing in the response.

So a block guessing from the browser language would sometimes put Dutch copy above English form labels. Pasting per translation is the only way to guarantee the block matches its surroundings.
